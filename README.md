# 몬스터 수학개념워크북 생성기

개념 내용을 1번만 입력하면 A4 3장(개념 정리 → 빈칸 채우기 → 백지 TEST)이
자동으로 만들어져 인쇄/PDF로 출력되는 프로그램입니다.

## 사용 방법

1. `몬스터_개념워크북_생성기.html` 파일을 더블클릭하면 브라우저에서 열립니다. (인터넷 불필요)
2. 화면에 3장이 순서대로 보입니다.
3. 위쪽 [인쇄 / PDF 저장] 버튼을 누르면 A4 3장으로 인쇄되거나 PDF로 저장됩니다.

## 폴더 안내

- `몬스터_개념워크북_생성기.html` — 프로그램 본체 (이 파일 하나면 실행됩니다)
- `docs/` — 기준 문서 (개발계획서, 디자인 샘플 v2, 초등 개념 목차표)

## 진행 상황

- [x] 1단계: 렌더링 엔진 — 개념 데이터 1개 → 3장 자동 생성 (일차함수 예제로 검증)
- [ ] 2단계: 개념 편집 화면 + 빈칸 드래그 지정 + 저장
- [ ] 3단계: 수식 입력(버튼 팔레트) + 수식 빈칸
- [ ] 4단계: 그림 1차 4종 (도형·분수모델·입체·그래프)
- [ ] 5단계: AI 초안 생성 연결
- [ ] 6단계: 그림 2차 3종 + 묶음 인쇄 + 백업
