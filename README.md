# 몬스터 수학개념워크북 생성기

개념 내용을 1번만 입력하면 A4 3장(개념 정리 → 빈칸 채우기 → 백지 TEST)이
자동으로 만들어져 인쇄/PDF로 출력되는 프로그램입니다.

인터넷 없이 파일 하나만 더블클릭하면 실행됩니다. 수식(분수·루트)까지 파일 안에
들어 있어 인터넷이 없어도 정상 표시됩니다. (단, AI 초안 생성 기능만 인터넷이 필요합니다.)

## 사용 방법

1. `몬스터_개념워크북_생성기.html` 파일을 더블클릭하면 브라우저에서 열립니다. (인터넷 불필요)
2. **개념 목록**: 저장된 개념이 카드로 보입니다. [새 개념 만들기]로 새로 시작합니다.
3. **개념 편집**: 왼쪽에 학교·학년·단원·키워드와 내용을 입력하면 오른쪽 미리보기에 바로 반영됩니다.
   - 빈칸 만들기: 본문에서 단어를 마우스로 선택(드래그)한 뒤 [선택한 부분 빈칸 지정]을 누르세요.
   - 수식: [+ 수식] 블록에서 분수·루트 등 버튼으로 입력합니다.
   - 그림: [+ 그림] 블록에서 도형·수직선·원·각도·분수모델·입체도형·쌓기나무·그래프를 숫자만으로 그립니다. 이름표는 미리보기에서 마우스로 끌어 옮깁니다.
   - 미리보기 위 탭으로 1단계(개념 정리) / 2단계(빈칸) / 3단계(백지 TEST)를 전환해 확인합니다.
   - [저장]을 누르면 개념 은행에 저장됩니다. (이 컴퓨터의 브라우저에 저장됨)
4. **목차(커리큘럼)**: [목차]에서 초3~고2 458개 개념·유형을 학년·단원별로 봅니다(초등 189개 + 중등 수학 유형 190개 + 고1 38개 + 고2 41개). 개념명 수정·추가·삭제, 확정(✔) 표시, 생성 여부 확인이 가능합니다.
   - 각 개념 줄에서 [AI 초안] 또는 [빈 개념]으로 바로 만들 수 있습니다.
   - 확정한 개념을 [확정 개념 일괄 생성]으로 순서대로 만들며, 한 개씩 검토 후 [저장하고 다음]으로 넘어갑니다.
5. **AI 초안**: [AI로 초안 만들기]에서 학년·단원·개념명만 넣으면 초안이 자동 작성됩니다. (먼저 [설정]에서 API 키 입력)
6. **검색 / 묶음 인쇄**: 목록 위 검색창으로 개념을 찾고, 카드 왼쪽 체크로 여러 개를 골라 [선택 묶음 인쇄]로 한 번에 뽑습니다.
7. **백업**: [백업]에서 모든 개념을 파일로 내보내거나 다시 가져옵니다. (다른 컴퓨터로 옮길 때 사용)
8. **인쇄**: [인쇄 / PDF] 버튼 → 3장이 나오면 [인쇄 / PDF 저장]을 누릅니다. A4 3장으로 나뉩니다.

## 폴더 안내

- `몬스터_개념워크북_생성기.html` — 프로그램 본체 (이 파일 하나면 실행됩니다)
- `docs/` — 기준 문서 (개발계획서, 디자인 샘플 v2, 초등 개념 목차표)

## 진행 상황

- [x] 1단계: 렌더링 엔진 — 개념 데이터 1개 → 3장 자동 생성 (일차함수 예제로 검증)
- [x] 2단계: 개념 편집 화면 + 빈칸 드래그 지정 + 저장 (개념 목록·복제·삭제·인쇄 포함)
- [x] 3단계: 수식 입력(버튼 팔레트) + 수식 빈칸 (KaTeX, 오프라인 시 안내 표시)
- [x] 4단계: 그림 1차 4종 (도형·분수모델·입체·그래프) + 파라미터 폼 + 라벨 끌어 옮기기
- [x] 5단계: AI 초안 생성 연결 (설정: API 키·학원 로고 업로드 포함)
- [x] 6단계: 그림 2차 3종(원·각도·수직선) + 쌓기나무 + 묶음 인쇄 + 검색 + 백업(내보내기/가져오기)
- [x] 목차(커리큘럼): 초3~고2 458개 목차(초등 189 + 중등 수학 유형 190 + 고1 38 + 고2 41), 수정·확정·생성 상태 관리 + 확정 개념 일괄 생성(한 개씩 검토)
