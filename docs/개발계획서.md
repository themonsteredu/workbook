# 몬스터 수학 개념워크북 생성기 — 개발 계획서

> 이 문서는 Claude Code에게 전달하는 개발 지시서이다.
> 발주자는 비개발자이므로, 진행 중 질문은 기술 용어 없이 해야 한다.

---

## 0. 제품 한 줄 정의

원장이 단원과 개념 내용을 입력하면, **동일한 내용의 A4 3장(개념 정리 → 빈칸 채우기 → 백지 TEST)** 이
실제 교재 품질로 자동 생성되어 인쇄/PDF로 출력되는 단일 HTML 프로그램.

디자인 기준: 첨부된 `몬스터_수학개념워크북_일차함수_샘플_v2.html` 의 레이아웃을 **그대로** 따른다.
(머리글 표: 학년 / 제목 / 학원 로고, 본문 표: 대단원 / 중단원 / 키워드 / 본문)

---

## 1. 핵심 설계 원칙 3가지

1. **하나의 원본 → 3장 자동 파생.**
   원장은 개념 내용을 1번만 입력한다. 1단계(전체), 2단계(빈칸), 3단계(백지)는
   같은 원본에서 렌더링 규칙만 바꿔 생성한다. 3장을 따로 만들게 하지 않는다.

2. **그림은 AI가 아니라 코드가 그린다.**
   그래프·도형은 파라미터(숫자) 기반으로 SVG를 코드가 생성한다.
   AI 생성 이미지·AI가 즉석에서 짜는 SVG 사용 금지 (품질 복불복 방지).

3. **개념 은행(확정본 저장).**
   AI는 초안만 제안하고, 원장이 수정·확정한 내용을 브라우저에 저장(localStorage 또는 JSON 파일 내보내기/불러오기).
   확정된 개념은 다음부터 AI 재생성 없이 그대로 재사용한다.

---

## 2. 데이터 구조 — "개념 1개"의 원본 형식

개념 1개는 아래 요소로 구성된 JSON 객체로 저장한다.

```json
{
  "id": "mid2-linear-func-01",
  "school": "중학교", "grade": "2학년",
  "unit_big": "일차함수",
  "unit_mid": "일차함수와 그래프",
  "keywords": ["일차함수", "기울기", "y절편", "x절편", "평행이동", "그래프"],
  "blocks": [ ...아래 블록 타입들... ]
}
```

### 블록 타입 (본문은 블록의 나열)

| 타입 | 용도 | 빈칸 처리 |
|---|---|---|
| `text` | 개념 설명 문단 | 문장 안 `{{ }}` 로 감싼 단어가 2단계에서 빈칸 |
| `formula` | 수식 (LaTeX) | `\bk{...}` 로 감싼 부분이 2단계에서 네모 빈칸 |
| `figure` | 그림 (파라미터 기반 SVG) | 라벨마다 blank 여부 플래그 |
| `table` | 용어 정리표 | 셀 단위 `{{ }}` 빈칸 |
| `writing` | 서술 답안 줄 (3단계용 점선 줄) | — |

### 빈칸 마킹 문법 (원장 입력 규칙)

- 텍스트: `이 함수를 {{일차함수}}라고 한다` → 1단계: 굵게 표시 / 2단계: 밑줄 빈칸 / 3단계: 문장 자체 미출력
- 수식: `y = \bk{a}x + \bk{b}` → 2단계에서 a, b 자리가 네모 빈칸
- 입력 화면에서는 원장이 문법을 몰라도 되도록, **단어를 드래그(선택)하고 "빈칸 지정" 버튼**을 누르면 자동으로 마킹되게 구현한다.

---

## 3. 수식 처리 계획

- 렌더링: **KaTeX** 사용 (MathJax보다 빠르고 인쇄 품질 안정적). CDN 로드 + 오프라인 대비 안내 문구.
- 저장은 LaTeX 문자열로. 예: `y = \dfrac{b}{a}x`, `\sqrt{2}`, `x^2`.
- 원장은 LaTeX를 모르므로 입력 화면에 **수식 버튼 팔레트** 제공:
  분수 / 거듭제곱 / 루트 / 부등호 / ± / π / ° / 절댓값 — 버튼 클릭으로 삽입, 실시간 미리보기 필수.
- 수식 빈칸(`\bk{}`)은 KaTeX `\boxed{\phantom{...}}` 또는 CSS 네모로 렌더링하되,
  **빈칸 크기는 정답 길이에 비례**시켜 답을 유추하기 어렵지 않게 한다 (최소 폭 보장).
- 인쇄 시 수식이 흐릿하지 않은지 반드시 인쇄 미리보기로 검증할 것.

## 4. 그림(figure) 처리 계획 — 가장 중요

### 4-1. 방식

그림은 "그림 타입 + 파라미터 + 라벨 목록"으로 저장하고, 코드가 SVG로 그린다.

```json
{
  "type": "figure",
  "figure_type": "coord_graph",
  "params": { "lines": [{ "slope": 2, "yIntercept": -2 }], "xRange": [-5,5], "yRange": [-5,5], "showGrid": true },
  "labels": [
    { "text": "기울기 a", "anchor": "on_line", "blank": true },
    { "text": "y절편 b", "anchor": "y_intercept", "blank": true },
    { "text": "x절편",  "anchor": "x_intercept", "blank": true }
  ],
  "stage3": "axes_only"
}
```

### 4-2. 단계별 렌더링 규칙

- 1단계: 그림 전체 + 라벨 텍스트 채움
- 2단계: 그림 전체 + `blank: true` 라벨은 **빈 박스만** 표시
- 3단계: `stage3` 옵션에 따름
  - `axes_only`: 좌표축·격자·직선만 남기고 라벨/보조점 제거 (일차함수 등 그래프 필수 단원)
  - `frame_only`: 도형 외곽만 남김
  - `none`: 그림 없이 서술 줄만

### 4-3. 그림 타입 카탈로그 — 이 순서로 개발 (**초등 콘텐츠를 먼저 만들기로 확정됨** → 초등 빈도순)

**1차 (필수, 먼저 완성 — 초등 수요 최다 4종):**
1. `basic_shape` — 삼각형/사각형/다각형 + 변·각·대각선 라벨, 넓이 공식용 밑변·높이 표시
2. `fraction_fig` — 분수 모델 (색칠된 원/막대, 진분수·가분수·대분수, 곱셈·나눗셈 모델)
3. `solid_fig` — 입체 (직육면체·각기둥·각뿔·원기둥·원뿔·구, 겨냥도, 전개도, 쌓기나무)
4. `stat_chart` — 그래프·표 (그림그래프, 막대, 꺾은선, 띠그래프, 원그래프)

**2차 (1차 검수 후 — 초등 나머지):**
5. `number_line` — 수직선 (소수·분수 위치, 이상·이하·초과·미만 범위 표시)
6. `circle_fig` — 원 + 중심/반지름/지름/원주 라벨
7. `angle_fig` — 각도 그림 (직각, 예각·둔각, 각도기, 삼각형 내각의 합)

**3차 (중등 콘텐츠 시작 시):**
8. `coord_graph` — 좌표평면 + 직선/곡선 (정비례·반비례, 일차함수, 이차함수)

**4차 (고등 콘텐츠 시작 시):**
9. `coord_graph` 확장 — 이차·삼차함수, 지수·로그, 삼각함수 곡선, 원과 직선, 넓이(적분) 표시

각 타입은 **파라미터 입력 폼**을 함께 만든다.
예: coord_graph는 "기울기, y절편 숫자만 입력 → 미리보기 즉시 갱신".
원장이 좌표나 SVG를 직접 다루는 일이 없어야 한다.

### 4-4. 그림 디테일 품질 기준

- 격자는 연한 회색, 축은 진한 선, 그래프 직선은 포인트 컬러(#E8500A) — 샘플 v2와 동일
- 라벨 박스는 그림 요소와 겹치지 않게 지시선(직선)으로 연결
- 라벨 자동 배치가 겹칠 경우를 대비해, 미리보기에서 **라벨을 마우스로 끌어 위치 조정** 가능하게 (조정값 저장)
- 인쇄 시 선이 깨지지 않도록 SVG 벡터 그대로 출력 (이미지 변환 금지)

## 5. AI 초안 생성 (보조 기능)

- 원장이 "학년 + 단원 + 개념명"만 입력하면 AI(Claude API)가 blocks 초안을 생성
- 프롬프트에 반드시 포함: 해당 학년 교육과정 수준, 5~8문장, 교과서 문체("~라고 한다"), 빈칸 후보 `{{ }}` 자동 표시, 그림이 필요한 개념이면 figure 블록 + 파라미터까지 제안
- **AI 초안은 무조건 편집 화면을 거쳐 원장 확정 후에만 저장** (자동 저장 금지)
- API 키는 원장이 설정 화면에 1회 입력, 브라우저에만 저장

---

## 6. 화면 구성 (단일 HTML)

1. **개념 목록** — 학년/단원별 저장된 개념 카드. 검색, 복제, JSON 내보내기/가져오기(백업용)
2. **개념 편집** — 좌: 블록 입력(텍스트/수식 팔레트/그림 폼/표), 우: 실시간 미리보기(1·2·3단계 탭 전환)
3. **인쇄** — 개념 1개 또는 여러 개 묶어서 3장 세트 연속 출력. A4, 여백 12mm, 페이지 나눔 정확히

머리글 로고: 학원 로고 이미지 파일을 설정 화면에서 업로드하면 전 페이지에 적용 (기본값: "더몬스터" 텍스트 원형 배지).

## 7. 개발 순서 (이 순서대로, 단계마다 원장 검수)

| 단계 | 내용 | 검수 기준 |
|---|---|---|
| 1 | 샘플 v2 레이아웃 → 렌더링 엔진화 (JSON 1개 → 3장 출력) | 일차함수 예제가 샘플 v2와 똑같이 나옴 |
| 2 | 개념 편집 화면 + 텍스트 빈칸 드래그 지정 + 저장 | 원장이 개념 1개를 직접 만들어 인쇄 성공 |
| 3 | KaTeX 수식 + 수식 팔레트 + 수식 빈칸 | 분수·루트 포함 개념 1개 인쇄 성공 |
| 4 | 그림 1차 카탈로그 4종 + 파라미터 폼 + 라벨 끌기 | 일차함수·수직선·삼각형·원 각 1개 인쇄 성공 |
| 5 | AI 초안 생성 연결 | 초안 품질을 원장이 직접 평가 |
| 6 | 그림 2차 카탈로그 + 묶음 인쇄 + 백업 | 실제 수업 1개 단원 전체 제작 |

한 단계 끝날 때마다 멈추고 원장에게 화면을 보여준 뒤 진행한다.
기술 스택: 단일 HTML + 바닐라 JS (기존 몬스터 워크북 생성기와 동일 방식), 배포는 Vercel 또는 로컬 파일 실행 둘 다 가능하게.
